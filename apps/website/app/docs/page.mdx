# Getting Started

Exphere explores a developer platform that connects product intent, delivery context, and cost. Start here to understand the project, try the local tools, and find the right reference.

## Choose your path

- **Understand the idea:** read [Concepts](/docs/concepts) for FinOps, agent-assisted delivery, and microruntimes.
- **Explore the design:** see [Architecture](/docs/architecture) for the proposed context and funding model.
- **Try the tools:** follow the local walkthrough below, then open the [CLI reference](/docs/cli).
- **Contribute:** use [Development](/docs/development) for workspace commands and review expectations.

## What is available today

| Surface | What you can do |
| --- | --- |
| Go CLI | Run help and version commands. |
| Documentation | Explore the product concepts, architecture, and development workflow. |
| Design and web packages | Use workspace design tokens and the shared ExphereShader React surface. |
| Project contracts | Inspect thirteen feature proposals and the documentary SDD lifecycle. |

The TypeScript SDK is a separate private package with an empty API. Runtime initialization, provisioning, agent orchestration, shared budget enforcement, and production integrations are not implemented.

## Run the project locally

You need repository access, Git, Node.js **22.22.1 or newer**, **pnpm 12.4.2**, and **Go 1.23+** for the CLI. The retained contract checks also use a POSIX shell and `jq`.

```sh
git clone https://github.com/jonatassales/exphere.git
cd exphere
pnpm install --frozen-lockfile
pnpm ex --help
pnpm ex version
```

The CLI prints its supported commands and scaffold version. These commands do not create a runtime or change consumer files.

Installation activates repository-local Husky hooks. It does not install `ex` globally or modify shell profiles. See [Development](/docs/development#hooks-and-review) for the checks those hooks perform.

## Open the website

```sh
pnpm dev --filter=website
```

Open the local address printed by Next.js and visit `/docs`. Shared packages build before the website starts. Stop the foreground process when finished.

Documentation search uses an index generated by the production build. To verify search locally, build and serve the production site as described in [Development](/docs/development#build-and-serve-the-website).

## About the homepage command

The homepage's `npx exphere init` command previews the intended interface. It is not a working onboarding command, and this repository does not demonstrate a published Exphere npm installer. Copying the command never executes it.
