# Synthetic consumer harness reference — 1.0.0

This source-only fixture is an inspectable target for later CLI generation. It is
not an installed service, deployable sample, second repository harness, or evidence
of paid execution. All identities, models, prices, budgets and resource choices are
synthetic. Existing applications are referenced, never copied into microruntimes.

The selected workflow follows the Exphere SDD stage IDs. The planner, MCP bindings,
retrieval and sensor handlers are deliberately unavailable. Contract validation can
pass while operational readiness fails. No hook or diagnostician is selected.

The reference contains no accounting history, cycle, approval, invoice or receipt.
Scenarios are separate test input. Configuration and selected assets are authored
content. Graph state, accounting, raw context and evidence are future generated
state with separate writers; see .exphere/guides/ownership.md.

No third-party skill source is vendored. The selected review-plan skill and its
supporting criteria were authored for this source fixture. The origin manifest
records source-only material, not an assertion of package publication or licensing
of the wider project. Conceptual reference: Birgitta Boeckeler, Harness engineering
for coding agent users, https://martinfowler.com/articles/harness-engineering.html.
